# Governance

Farfield is currently maintained by the Farfield team. Maintainers are responsible for releases, security response, compatibility decisions, and repository moderation.

Technical decisions should be made in public issues or pull requests when practical. Changes to persisted protocols, security boundaries, licensing, governance, or backward compatibility require explicit maintainer review and a written rationale.

As outside maintainers emerge through sustained high-quality contributions and community support, this document will be expanded with a transparent nomination and decision process.
